    标题

    Docker 引擎

    dockfile 直连 Docker Engine API。Windows 上没有 docker 时，会自动桥接 WSL 里的 docker.sock。

    快捷键

    ↑↓移动光标
    Enter打开目录 / 预览文件
    Backspace返回上级
    Alt+←后退
    Ctrl+L聚焦路径输入框
    Del删除选中
    F2重命名选中
    Ctrl+S保存编辑
    Esc关闭抽屉 / 弹窗
    ?本帮助

    拖拽文件或文件夹到列表即可上传；上传目录会保留相对路径。
